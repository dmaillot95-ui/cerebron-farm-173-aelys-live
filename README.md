## Absolute rules

- REALITY > COHERENCE
- EVIDENCE > CONFIDENCE
- CLAIM <= EVIDENCE
- MEMORY != TRAINING
- SIMULATION != TEST
- no public GitHub storage of private client conversations
- no automatic training from live chat
- no M4/GOLD or neural-training release while global F72 is FAIL
- every external platform adapter starts UNQUALIFIED and must pass an executable canary before activation
- secrets are environment-only and are never committed
